Conectar ao Asana

Cole um Personal Access Token do Asana (Configurações → Apps → Gerenciar Token de Acesso Pessoal). Ele fica salvo apenas no armazenamento local deste navegador — nunca é enviado a nenhum outro lugar.

Dica: se a conexão falhar por bloqueio de CORS ao abrir o arquivo direto (file://), sirva a pasta com um servidor local simples (ex: npx serve) e abra via http://localhost.

Qual cliente/projeto?

Cada cliente é um projeto separado no Asana. O histórico da reunião (peças já decididas, pendências, etc.) fica guardado por projeto — trocar de cliente aqui não apaga nada dos outros.
